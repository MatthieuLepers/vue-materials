# Vue Materials

Vue Materials is a Vue 3 component library built with TypeScript and SCSS.

This Storybook is the component workbench for the design system. Stories should document the public API of each component, including its meaningful variants, states, slots, events, and interaction patterns.

## Conventions

- Keep stories focused on one component or closely related subcomponents.
- Prefer realistic examples over isolated placeholder values.
- Use Controls for meaningful public props and Actions for emitted events where applicable.
- Document required providers, plugins, or global styles when a component depends on them.
- For generic components, provide representative typed examples without weakening the component's public types.
